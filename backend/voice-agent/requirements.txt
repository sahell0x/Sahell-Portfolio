# Trimmed dependency set for the portfolio voice agent.
#
# vox/ ships no dependency list of its own. Its provider registries resolve
# lazily (see vox/providers.py), so only the Sarvam + OpenAI + default-web path
# is ever imported and Azure Speech, Google Cloud Speech, Polly/boto, Twilio,
# Plivo, litellm and groq are all unnecessary. The transport is a plain
# WebSocket served by uvicorn, so it needs no client library of its own.
#
# Python 3.12 is required: vox uses the stdlib `audioop` module, which was
# removed in 3.13.
